# POVForge

Focused workflow studio for high-volume stick-figure psychology explainers (PsychToons style).

## What it covers

- Exact script structure these channels use (hook → reframe → mechanism → status flip → rules → close)
- Beat-level prompt builder targeting 200–350 stills
- Locked visual system for character consistency
- Production rules: light motion, frequent cuts, calm second-person voice

All client-side. No backend.
